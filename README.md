# Number Converter

A simpler C++ console program that converts between decimal, binary, and hexadecimal (including negative numbers in 8, 16, or 32-bit two's complement), and shows how a number is stored as a 32-bit IEEE 754 float.

## Files

```
main.cpp              the menu and one function per menu option
BaseConverter.h/.cpp  decimal/binary/hex conversion and two's complement
FloatConverter.h/.cpp 32-bit float: sign, exponent, and mantissa
```
